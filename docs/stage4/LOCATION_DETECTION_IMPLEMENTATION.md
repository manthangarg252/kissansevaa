# KissanSevaAI Stage 4 — Automatic Farm Location Implementation

## 1. Permissions & Single-Shot Location Service

- **Manifest & Dependencies**: Added `com.google.android.gms:play-services-location:21.3.0` via [libs.versions.toml](file:///Users/manthangarg/Desktop/kissansevaai-main/android/gradle/libs.versions.toml) and [build.gradle.kts](file:///Users/manthangarg/Desktop/kissansevaai-main/android/app/build.gradle.kts), and declared `ACCESS_COARSE_LOCATION` and `ACCESS_FINE_LOCATION` in [AndroidManifest.xml](file:///Users/manthangarg/Desktop/kissansevaai-main/android/app/src/main/AndroidManifest.xml). Background location (`ACCESS_BACKGROUND_LOCATION`) is intentionally **not** requested.
- **Single-Shot Detector & Async Geocoder** ([AndroidLocationService.kt](file:///Users/manthangarg/Desktop/kissansevaai-main/android/app/src/main/kotlin/com/kissansevaai/core/location/AndroidLocationService.kt), [LocationModels.kt](file:///Users/manthangarg/Desktop/kissansevaai-main/android/app/src/main/kotlin/com/kissansevaai/core/location/LocationModels.kt), [LocationModule.kt](file:///Users/manthangarg/Desktop/kissansevaai-main/android/app/src/main/kotlin/com/kissansevaai/core/location/LocationModule.kt)):
  - Checks runtime fine/coarse permissions, GPS/Network location enablement, and Google Play Services availability (`GoogleApiAvailability`).
  - Uses `FusedLocationProviderClient.getCurrentLocation(...)` with a `12_000L` ms timeout, distinguishing `gps_precise` (`ACCESS_FINE_LOCATION`) vs `gps_approximate` (`ACCESS_COARSE_LOCATION`).
  - Explicitly rejects stale fixes older than `MAX_LOCATION_AGE_MS` (`15` minutes) via `LocationDetectionResult.NullOrStaleLocation` and handles `PermissionDenied`, `LocationServicesDisabled`, `PlayServicesUnavailable`, and `Timeout` cleanly.
  - Reverse geocodes asynchronously using Android `Geocoder.GeocodeListener` on API 33+ and `Dispatchers.IO` on older APIs, never inventing a missing `district` field when geocoder metadata omits `subAdminArea`.

## 2. Confirmation UX & Separation of Phone vs. Saved Farm Location

- [FarmLocationComponents.kt](file:///Users/manthangarg/Desktop/kissansevaai-main/android/app/src/main/kotlin/com/kissansevaai/ui/component/FarmLocationComponents.kt) implements `rememberFarmLocationPrompt` and `FarmLocationConfirmationDialog` (`"Use this location for your farm?"`).
- Displays **`Current Phone Location`** (locality, district/state, coordinates, and accuracy/source badge such as `GPS Precise (±5m)`) side by side with **`Saved Farm Location (Current)`** so ephemeral phone movement never silently overwrites a saved farm profile.
- Provides three explicit user actions: **`Confirm`**, **`Change Location`** (manual editable `Farm Name`, `Village / Locality`, `District`, and `State` with `VoiceInputField` support), and **`Retry Detection`**.
